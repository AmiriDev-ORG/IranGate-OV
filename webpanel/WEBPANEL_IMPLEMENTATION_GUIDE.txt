✅ SETTINGS API:

   GET    /api/settings/server            - Get server settings
   PUT    /api/settings/server            - Update server settings

✅ BACKUP API:
   GET    /api/backup/export              - Export backup

✅ SECURITY FEATURES:

STEP 1: Prepare Backend Dependencies
-------------------------------------

cd /root/ov/irangate/webpanel/backend

Create go.mod:
```
module irangate-webpanel

go 1.24

require (
    github.com/golang-jwt/jwt/v5 v5.2.0
    github.com/gorilla/mux v1.8.1
    github.com/gorilla/handlers v1.5.2
)
```

Then run:
$ go mod download
$ go mod tidy


STEP 2: Build and Run Backend
------------------------------

$ cd /root/ov/irangate/webpanel/backend

This will start the API server on http://0.0.0.0:8080

================================================================================
                    TROUBLESHOOTING
================================================================================

PROBLEM: Can't login to web panel
SOLUTION:
1. Check if API server is running: ps aux | grep webpanel
2. Check logs: tail -f /var/log/irangate-webpanel.log
3. Verify credentials in /opt/irangate/webpanel/admin.json
4. Reset password if needed

PROBLEM: Clients not appearing
SOLUTION:
1. Check if irangate CLI works: irangate client list
2. Verify API can execute commands
3. Check permissions on database files
4. Verify irangate is in PATH

PROBLEM: Can't remove clients
SOLUTION:
1. Check if user has sudo privileges
2. Verify irangate remove works from CLI
3. Check API logs for errors

PROBLEM: Templates not saving
SOLUTION:
1. Check /opt/irangate/webpanel/templates/ permissions
2. Verify disk space: df -h
3. Check API logs

                    QUICK START COMMANDS
================================================================================

# Install web panel dependencies
cd /root/ov/irangate/webpanel/backend
go mod download

# Build web panel
go build -o webpanel api.go

# Run web panel (foreground)
./webpanel

# Run web panel (background)
nohup ./webpanel > /var/log/irangate-webpanel.log 2>&1 &

# Create systemd service
sudo nano /etc/systemd/system/irangate-webpanel.service

[Unit]
Description=IranGate Web Panel
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/ov/irangate/webpanel/backend
ExecStart=/root/ov/irangate/webpanel/backend/webpanel
Restart=always

[Install]
WantedBy=multi-user.target

# Enable and start service
sudo systemctl enable irangate-webpanel
sudo systemctl start irangate-webpanel
sudo systemctl status irangate-webpanel

================================================================================
                    FRONTEND TEMPLATE (MINIMAL)
================================================================================

Since the full frontend is too large, here's a minimal starting point:

Create: /root/ov/irangate/webpanel/frontend/index.html

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>IranGate - Login</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-gray-100">
    <div class="min-h-screen flex items-center justify-center">
        <div class="bg-white p-8 rounded-lg shadow-md w-96">
            <h1 class="text-2xl font-bold mb-6 text-center">IranGate Web Panel</h1>
            <form id="loginForm">
                <div class="mb-4">
                    <label class="block text-gray-700 mb-2">Username</label>
                    <input type="text" id="username" class="w-full px-3 py-2 border rounded" required>
                </div>
                <div class="mb-6">
                    <label class="block text-gray-700 mb-2">Password</label>
                    <input type="password" id="password" class="w-full px-3 py-2 border rounded" required>
                </div>
                <button type="submit" class="w-full bg-blue-500 text-white py-2 rounded hover:bg-blue-600">
                    Login
                </button>
            </form>
            <div id="error" class="mt-4 text-red-500 text-center hidden"></div>
        </div>
    </div>
    <script>
        document.getElementById('loginForm').addEventListener('submit', async (e) => {
            e.preventDefault();
            const username = document.getElementById('username').value;
            const password = document.getElementById('password').value;
            
            try {
                const response = await fetch('http://localhost:8080/api/login', {
                    method: 'POST',
                    headers: { 'Content-Type': 'application/json' },
                    body: JSON.stringify({ username, password })
                });
                
                const data = await response.json();
                
                if (data.success) {
                    localStorage.setItem('token', data.data.token);
                    window.location.href = 'dashboard.html';
                } else {
                    document.getElementById('error').textContent = data.message;
                    document.getElementById('error').classList.remove('hidden');
                }
            } catch (error) {
                document.getElementById('error').textContent = 'Connection error';
                document.getElementById('error').classList.remove('hidden');
            }
        });
    </script>
</body>
</html>
```
