API Documentation

Interactive REST API reference for IranGate

Authentication

POST /api/login

Login and receive JWT token

Request:

{
  "username": "admin",
  "password": "admin123"
}

Response:

{
  "success": true,
  "data": {
    "token": "eyJhbGc...",
    "username": "admin",
    "expires_at": "..."
  }
}

Client Management

GET /api/clients

List all VPN clients

POST /api/clients

Create new client

{"name": "john"}
DELETE /api/clients/{name}

Remove client (revokes certificate!)

GET /api/clients/{name}/export

Download .ovpn configuration file

GET /api/clients/{name}/status

Check certificate status (Valid/Revoked/Expired)

GET /api/clients/orphaned

List orphaned certificates (security risk!)

POST /api/clients/cleanup-orphaned

Revoke all orphaned certificates

Other Endpoints

GET /api/config - Get OpenVPN config
GET /api/monitor/stats - Server statistics
GET /api/server/status - Server status
POST /api/server/restart - Restart OpenVPN
GET /api/users - List admin users
POST /api/users - Create admin user
GET /api/groups - List client groups
POST /api/groups - Create group
GET /api/backup/export - Export backup
POST /api/backup/import - Import backup

Code Examples

cURL Example:

curl -X POST http://localhost:8080/api/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'

JavaScript Example:

const token = localStorage.getItem('token');
const response = await fetch('/api/clients', {
  headers: { 'Authorization': `Bearer ${token}` }
});
const data = await response.json();
